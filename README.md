# مكتب الجهيني للخدمات الحكومية

موقع عربي متجاوب مع نموذج استفسارات ولوحة إدارة محمية بحساب Supabase Auth.

## المطلوب
- Node.js 20 أو أحدث
- مشروع Supabase

## الإعداد
1. افتح مشروع Supabase ثم SQL Editor، وشغّل محتويات `database.sql`.
2. انسخ `.env.example` إلى ملف جديد اسمه `.env`.
3. املأ `SUPABASE_URL` و`SUPABASE_ANON_KEY` و`SUPABASE_SERVICE_ROLE_KEY` من إعدادات مشروعك.
4. حدّد بريد المدير في `ADMIN_EMAIL`، واجعل `COOKIE_SECRET` قيمة عشوائية طويلة لا تقل عن 32 حرفًا.
5. من Supabase Authentication > Users، أنشئ حسابًا ببريد المدير نفسه وكلمة مرور قوية.
6. من مجلد المشروع شغّل `npm install` ثم `npm start`.
7. افتح `http://localhost:3000`، ولوحة الإدارة من `/admin-login.html`.

## النشر
اضبط متغيرات البيئة نفسها في منصة الاستضافة، واجعل `NODE_ENV=production` حتى تُستخدم ملفات جلسة آمنة عبر HTTPS. لا ترفع `.env` إلى Git ولا تكشف مفتاح `service_role` للمتصفح.

## ملاحظات
- نموذج الموقع لاستفسارات مبدئية فقط، وليس خدمة إصدار مستندات رسمية.
- الأوراق المطلوبة إرشادية ويجب التأكد من الجهة المختصة.
- قبل الإنتاج، راجع حماية CSRF وسياسات الجلسات والاحتفاظ بالبيانات، واختبر كل المسارات في بيئة تجريبية.
